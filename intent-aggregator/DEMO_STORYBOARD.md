# 意图聚合器 · 30 秒录屏分镜

自己录屏。界面是英文 Demo，徽章是 “Demo data. Real API not called.”。每条旁白不超过 60 个汉字。

## 0–5s

- 画面：打开 `http://127.0.0.1:8788/`，停在标题 “Intent Aggregator Demo” 和徽章上。下拉框停在 “Customer intent”，文本框是空的。
- 操作：不点击。
- 旁白：任何一句话，3 秒钟知道对方想干嘛。

## 5–15s

- 画面：点 “Fill example”，文本框出现晚到退款那段。点 “Analyze”。结果从上方滑入，“Suggested action” 在最上面。光标停在 Intent 卡片的概率条上，再移到灰色的 “For reference only”。
- 操作：Fill example → Analyze → 指向置信度条。
- 旁白：贴上退款原话，点分析，先看有多确定。

## 15–23s

- 画面：场景改成 “Meeting read”。再点 “Fill example”，出现老板打断、获客成本上涨那段。点 “Analyze”。镜头停在 Stance、Pushback、Next step 三张卡片。
- 操作：切换场景 → Fill example → Analyze。
- 旁白：换成会议，看立场、阻力和下一步。

## 23–30s

- 画面：切到一张结尾卡。一行字：Jev 只做判断：想干嘛，有多确定，下一步干嘛。下面是仓库地址 `github.com/lilaclilac09/aileen_machina_01` 和本地地址 `127.0.0.1:8788`。
- 操作：停住，不要再点。
- 旁白：Jev 只做判断：想干嘛，有多确定，下一步干嘛。
