# Icon map key

17 Aug 2026. Figure: `fig-map-icons.png` / `fig-map-icons.svg`. FX **7.2 yuan/USD**. Pins are geography, not a door census. Do not weld a city to a door.

## What each icon is

| Icon | Meaning |
|---|---|
| Wind turbine (green, solid) | Wind in the **physical** mix, or a named wind plant / offshore wind into the campus story |
| Wind turbine **dashed** (ring) | **Virtual PPA** — not physical into the hall. Zhongwei Unicom: 1.5 GW wind virtual |
| Sun (gold, solid) | Solar / PV physical, or regional PV on the same grid |
| Sun small / faint | Planned or secondary (Changshu GDS on-site PV-storage, not a 2026 meter) |
| Hydro drop (teal) | Hydro in the mix. Changshu: West-to-East into the **city**, faint. Shaoguan: city hydro+PV |
| Grey bolt | Grid. Always drawn when the hall is on a grid mix, except Hai Lan Yun (offshore wind **direct**, no bolt) |
| Navy **$ badge** | Door USD at 7.2, when a public yuan/kWh exists |
| Grey **unstated** badge | No public door meter. **No USD invented.** Hai Lan Yun: `demo 2.3 MW` (filing, not a western-China door). Johor: `unstated ¢` plus Singapore ruler $0.23/kWh |
| Teal **fan** | Air-cooled. Rooftop AHU rows or side-wall outdoor arrays seen, or air typical for that park type |
| Blue **wave** | Seawater / underwater. Hai Lan Yun cabin only. Orbit-invisible |
| Grey **?** (cooling) | Satellite did not show halls / cooling plant. Qingyang mosaic predates the park; Changshu GDS sat showed warehouses; Shaoguan and Johor unstated from sat |
| Small **tower** + “copy only” | Cooling towers in **company copy**, not on the public mosaic. GLP Changshu SE only |
| Thermometer | **City climate**, not a hall sensor. July / annual mean **°F** (CMA source is °C, shown small) |
| Letter chips | Offtaker **letters, not logos**. See below. Unnamed stays `?`. Do not weld |
